# Machine Learning Sentiment Analysis

### Analysis of an Amazon customer review dataset 

## Task
Use Explanatory Data Analysis techniques to explore an Amazon customer review dataset to gain initial insights of the dataset. Then, we apply statistical methods to uncover predictors of customer review behavior. Finally, implement Sentiment Analysis algorithms to read the reviews and predict their classification into either a positive or negative category.

## Summary of Tech Stack
This project was built using Jupyter notebooks using python programming language. The libraries used include pandas, seaborn and matplotlib, scipy, scikit-learn, numpy, and imblearn. These libraries allow explanatary analysis tools as well as 
statistical analysis tools to be utilized on the dataset and finally machine learning capability to be harnessed for classification of the reviews.
